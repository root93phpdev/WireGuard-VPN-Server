# WireGuard VPN Server

Документация персонального инфраструктурного проекта: развёртывание WireGuard VPN на Ubuntu VPS, настройка firewall, NAT, systemd и клиентов Windows/Android.

Репозиторий содержит обезличенные примеры и инструкции. В нём **нет** рабочих приватных ключей, реальных конфигураций клиентов, production-конфигурации сервера или резервных архивов.

## Характеристики стенда

| Компонент | Значение |
|---|---|
| ОС | Ubuntu 26.04.1 LTS |
| Виртуализация | KVM VPS |
| VPN | WireGuard |
| Интерфейс | `wg0` |
| VPN-подсеть | `10.8.0.0/24` |
| Адрес сервера в VPN | `10.8.0.1/24` |
| Порт | UDP `51820` |
| Внешний интерфейс | `eth0` |
| Firewall | UFW |
| NAT | iptables MASQUERADE |
| Управление сервисом | systemd (`wg-quick@wg0`) |
| Проверенные клиенты | Windows, Android |
| Маршрутизация | Полный IPv4-туннель |

## Что реализовано

- WireGuard-сервер с отдельными ключами для каждого устройства.
- IPv4 forwarding и NAT для VPN-клиентов.
- Правила UFW для входящего и маршрутизируемого трафика.
- Усиление SSH: вход по ключам, запрет root login и парольной аутентификации.
- Автозапуск WireGuard через systemd.
- Примеры конфигураций Windows и Android.
- Скрипт диагностики без внесения изменений.
- Инструкции по резервному копированию и восстановлению.
- Защита репозитория от случайной публикации секретов.

## Проверки

В реальном развёртывании проверены:

- WireGuard handshake с Windows и Android.
- Доступность VPN-адреса сервера `10.8.0.1`.
- Выходной публичный IPv4 через VPS.
- DNS через `1.1.1.1`.
- Счётчики трафика и время последнего handshake.
- Автозапуск сервиса и повторное подключение клиентов после перезагрузки VPS.

## Ограничения

- Настроен IPv4 full tunnel; IPv6-туннель не входит в текущий объём проекта.
- Один VPS, без высокой доступности и автоматического переключения.
